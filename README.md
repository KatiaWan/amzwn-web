# AMZWN Web

第七期“关键词作战总表”前台仓库。

## 页面

- `/`：邮箱注册与登录。
- `/tool/`：提交 ASIN 与 `.xlsx`／`.csv` 广告搜索词报表，查看最近 10 条任务。
- `/report/?task=<uuid>`：校验任务归属后，在线读取并渲染已完成报告。

报告页为每个关键词显示“放量、守位、试投、止损、换长尾、观察”六类作战信号，并在表格上方提供带数量的信号下拉筛选。关键词／ASIN 即时搜索、筛选、结果计数和分页相互联动，每页显示 50 个词。关键词表格随网页自然展开；浏览关键词板块时，页面底部只显示一条跟随式横向滑条，离开板块后自动隐藏。这些操作只处理已加载的报告，不会重新调用数据接口或产生 Credit。

## 模块3第一阶段（仅本地，尚未发布）

- 路径 A：为自己的已完成任务补充 3–5 个竞品和选填核心关键词，不重新上传报表、不重跑 01—03。
- 路径 B：新任务首次提交时同时保存模块3配置，普通任务仍沿用原四态。
- 工具页可查询独立模块3状态、导入不超过 256 KB 的 `product-media.json`，并分别执行媒体人工确认、费用授权和结果确认。
- 媒体导入使用一次性 nonce；前端校验只用于提示，任务所有权、配置修订、ASIN 集合和状态均由服务器重新核验。
- 运行本地纯函数测试：`node test-module3-form.mjs`。

当前代码依赖尚未应用的 `05_module3_workflow.sql` 和尚未部署的模块3 API；不得直接发布本前台。

## 本地预览

在本目录启动静态服务器：

```text
python -m http.server 8766 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8766/`。

## 安全约束

- 前端只包含 Supabase 公开 publishable key。
- 万能钥匙、OSS、西柚、豆包与 SSH 凭证不得进入本仓库。
- 输入报表上传到私有桶 `keyword-inputs`，路径固定为 `{user_id}/{task_id}.{ext}`。
- `keyword_tasks` 与 Storage 均由 Supabase RLS 限制为当前登录用户。
- Supabase 浏览器库已固定到本地 `vendor/supabase-2.114.0.js`，许可证见同目录。
- 报告内容在沙箱 iframe 中显示，报告脚本仍被禁止；仅开放父页面读取表格，以实现本地搜索、分页、自然高度和跟随式横向滑条。
- 媒体清单中的 URL 不由服务器访问、下载、探测或跟随重定向；服务器只接受 HTTPS 且精确域名为 `m.media-amazon.com` 的结构化记录。
